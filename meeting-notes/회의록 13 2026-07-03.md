## ✅ 결정 내용

### 1) 자소서 작성 방향

**목적:**

채용 담당자가 지원자의 실제 업무 방식과 협업 방식을 구체적으로 상상할 수 있는 자소서 작성

**작성 기준:**

- 문제를 어떻게 정의했는지 작성
- 문제를 해결하기 위해 어떤 판단을 했는지 작성
- 팀원들과 어떤 방식으로 협업했는지 작성
- 결과보다 과정과 사고방식을 중심으로 작성
- 읽는 사람이 실제 업무 수행 모습을 상상할 수 있도록 작성

---

### 2) 개발자 역량 성장 방향

**학습 목표:**

알고리즘뿐만 아니라 서비스 전체 구조를 이해할 수 있는 개발자로 성장

**중점 학습 분야:**

- 자료구조(Data Structure)
- 운영체제(OS)
- 데이터베이스(DB)
- 네트워크(Network)

**추가 논의 사항:**

- AI를 단순 코드 생성기가 아닌 리뷰어로 활용하는 방법 고민
- AI가 생성한 결과물에 대한 검증 및 책임은 개발자가 수행
- 기술 자체보다 문제 해결과 비즈니스 이해를 우선적으로 고려

---

### 3) 도메인 기반 기술 선택 역량 강화

**목표:**

기술 선택의 이유를 비즈니스 관점에서 설명할 수 있는 개발 역량 확보

**학습 방향:**

- 왜 해당 기술을 선택했는지 설명 가능해야 함
- 최신 기술이라는 이유가 아니라 문제 해결 적합성을 기준으로 판단
- A 기술 대신 B 기술을 선택한 이유를 명확히 정리
- 도메인 요구사항과 기술 선택의 연결 관계를 학습

---

### 4) CS 학습 및 정리 방법

**학습 방법:**

- 정보처리기사 범위를 활용한 기초 CS 학습
- 알고리즘 및 CS 문제 풀이 병행
- 학습 내용을 프로젝트와 연결하여 정리

**정리 기준:**

#### 프로젝트와 관련 있는 경우

- 현재 프로젝트에서 사용 중인지 확인
- 왜 사용하는지 정리
- 어떻게 활용되고 있는지 정리
- 향후 확장 가능성 검토

#### 프로젝트와 관련 없는 경우

- 현재 사용하지 않는 이유 정리
- 어떤 상황에서 활용 가능한지 정리
- 향후 적용 가능한 프로젝트 검토

---

## 📌 참고

- 자소서는 문제 정의 → 해결 과정 → 협업 → 결과 순으로 작성
- 기술 학습 시 단순 개념 암기보다 프로젝트 적용 관점으로 정리
- 기술 선택 시 비즈니스 요구사항과의 연결성을 우선 고려
