## ✅ 결정 내용

### 1) 스터디 운영 방식 및 규칙 정하기  
- 아침운동
    - 아침운동 10분 이상
    - 시작, 종료 사진 카톡으로 증명
    - 월 ~ 금
      
- 코딩테스트
    - 자료
      : 프로그래머스 입문 -> 기초 -> SQL
    - 진행 방식
      : 코딩문제풀기 15 -> 코드리뷰 15
      
- 알고리즘
    - 자료
        : 딩코딩코 알고리즘 강의
    - 학습 진행방식(125분)
        - 1차 학습(60분) : 강의20 → 구현5 → 체크5 → 학습10 → 재구현10 → 리뷰10
        - 복습(30분) : 전날 문제10 → 체크5 → 전전날 문제 10 → 체크5
        - 2차 학습(35분) : 1차학습문제10 → 체크5 → 리뷰10 → 정리10
    - 평가 진행방식
        - 격주 평가(every two weeks 알고리즘 개념 평가) : 격주 토요일에 3회 습득한 알고리즘 개념 구현(140)
            - 진행 방식
              : (1문제10 → 체크5) * 4회 → (학습10 → 리뷰10) * 4회 → 체득하지 못한 알고리즘 체크리스트 작성5
        - 월말 평가(monthly 알고리즘 평가) : 한달동안 학습한 모든 알고리즘 문제풀기(320분)
            - 진행 방식
              : 8문제120 → (체크5 → 학습10 → 리뷰10) * 8회 → 체득하지 못한 알고리즘 체크리스트 작성5
    - 용어
        - 체크 : 체크 항목을 바탕으로 문제점 찾기
        - 리뷰 : 체크 항목을 바탕으로 내가 한 시도를 텍스트로 작성
        - 정리 : 오늘 학습한 알고리즘 정리
      
- 지식 학습
    - 지식 학습
        : easy-ing(MySQL), ramgthunder(Spring)를 바탕으로 학습 및 발표
    - 관심분야 학습
        : 각 관심분야 학습 및 발표
    - 진행 방식
        : 읽기40 → 정리10 → 쉬는시간10 → 발표15*2 → PullRequest10 → 답변10 

- 구직활동
    - 주 당 최소 지원횟수 : 6회
    
- 프로젝트
    - 공통프로젝트[공강]
        - 목적 : 
    - 개인프로젝트

- 규칙
    - 벌금 목록
        - 아침운동 미 시행 5000원
        - 지각 1 분당 1000원

- 담당자 : easy-ing, ramgthunder
