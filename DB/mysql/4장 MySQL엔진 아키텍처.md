# 4장 MySQL엔진 아키텍처

MySQL 서버는 사람의 머리 역할을 담당하는 MySQL 엔진과 손발 역할을 담당하는 스토리지 엔진으로 구분된다.

### 4.1 MySQL 엔진 아키텍처

### 4.1.1 MySQL 전체 구조

MySQL 엔진

- 요쳥된 SQL 문장을 분석하거나 최적화를 담당, 아래와 같이 구성되어 있음
- 커넥션 핸들러 : 클라이언트로부터 접속 및 쿼리 요청 처리
- SQL 파서 : SQL 쿼리를 알맞은 토큰으로 분리 후 트리로 변환
- 전처리기 : 토큰 트리를 문법으로 인식해, 문법적 오류가 있는지 확인
- 옵티마이저 : 쿼리 실행문 최적화

스토리지 엔진

- 실제 데이터를 디스크 스토리지에 저장하거나 디스크 스토리지로부터 데이터를 읽어옴
- 즉, 실제 파일 시스템과 관련된 일 담당
- MySQL 서버에서 MySQL 엔진은 하나지만 스토리지 엔진은 여러 개를 동시에 사용 가능

핸들러 API

- MySQL 엔진 -> 스토리지 엔진 데이터를 쓰기 또는 읽기 요청하면서 사용되는 API
- 스토리지 엔진 -> MySQL 엔진 데이터를 주고 받을 때 사용되는 API
