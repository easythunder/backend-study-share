## localhost vs TCP/IP

localhost와 IP 접속은 겉으로는 비슷해 보이지만 내부적으로는 방식이 다릅니다.

localhost로 접속하는 경우에는 일반적으로 Unix socket 방식을 사용해서 같은 서버 내부에서 파일 기반으로 연결되고, 
이 경우에는 네트워크 포트를 거치지 않습니다. 
반면 127.0.0.1이나 실제 서버 IP로 접속하는 경우에는 TCP/IP 방식으로 동작하며, 
이때는 MySQL 서버가 열어둔 포트(기본 3306)를 통해 연결됩니다.

이 차이 때문에 접속 경로뿐 아니라 인증 정보도 user@localhost와 user@'127.0.0.1'처럼 다르게 인식될 수 있어서, 
실제 사용 시 권한이나 접속 오류 원인을 이해하는 데도 중요한 포인트입니다.
